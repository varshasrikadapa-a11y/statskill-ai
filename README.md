# StatSkill AI

### Building a Future-Ready Statistical Workforce

SIH Problem Statement 101 — AI-Powered Competency & Learning Platform for Official Statistics.

StatSkill AI is planned as a government-grade learning and competency intelligence platform for MoSPI / NSSTA and India's National Statistical System.

## Development Stages

We will build and commit the project incrementally so the team can review every milestone.

| Stage | Deliverable | Status |

| 5 | Trainer / Faculty mode | 🔜 |
| 6 | Administrator mode | 🔜 |

## Three Experiences

- **Learner — My Growth**
- **Trainer — My Cohort**
- **Administrator — My Workforce**

## Demo Flow

Landing → Login → Learner Dashboard → Skill Gap → Explainable Recommendation → Learning Path → Assessment → Competency Improvement → Trainer Question Review → Source Verification → Administrator Workforce Heatmap → Future Skills Forecast → iGOT Integration.
